# 洗车房 · 工位与洗车单

洗车房的日常台账：**工位**、**洗车单**、**耗材**、**会员卡**。

业务重点：
- **状态用枚举写**（`enums/WashState` 等），状态机规则也放在枚举上（`canMoveTo`），
  洗车单只能「待洗 → 清洗中 → 已完成」一步步走，跳步和回退都会被拦；
- **回炉台**（`rework_order`）：回炉只挂在已完成的单上，同一原单同时只允许一张未验收的回炉；
  回炉自己按「待回炉 → 回炉中 → 已验收」走，不许跳步倒退，也不许一上来就验收；
  挂回炉先认原工位，原工位停用、有没洗完的车或占满了才允许改派到别的空闲工位，
  认不上又选不到空位时当场报原因；原单挂着未验收回炉时列表和详情都标「回炉未结」；
- **工位占用一个口径**（`BayOccupancy`）：没洗完的单 + 回炉中的回炉都算占位，
  占满了开不了新单也接不了回炉；停用工位时上面的回炉只能改派不能拆，改派不到空位整次停用失败；
- **耗材出库**封装在实体里（`Supply.consume`），不够就不给用，见底自动标成已用完；
- **会员卡扣费**（`MemberCard.pay`）：停卡或余额不足都扣不动。

## 技术栈

- 后端：Spring Boot 3.3 / Java 17、Spring Data JPA（**状态一律用枚举 + `@Enumerated(EnumType.STRING)`**）、
  MySQL 8、Redis 7
- 前端：Vue 3（Options API，页面逻辑主要靠 computed 串起来）+ Element Plus + Vite
- 一键起：`./start.sh`

## 业务模块

1. **工位**（`bay`）—— 编号名称、同时容纳、空闲/占用/停用，占用数含在洗单和回炉中单
2. **洗车单**（`wash_order`）—— 单号车牌、工位、服务与金额、三态流转、回炉未结标
3. **回炉**（`rework_order`）—— 挂在已完成单上、占一个工位、三态流转到验收
4. **耗材**（`supply`）—— 编号名称单位、库存与预警线、正常/不足/已用完
5. **会员卡**（`member_card`）—— 卡号持卡人、余额与等级、正常与停卡
